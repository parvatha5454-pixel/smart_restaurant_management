# Saffron & Root | VibeAthon 6.0 Submission
> **Saffron & Root** is a modern, responsive single-page web application designed for a smart, immersive restaurant experience. It blends contemporary UI/UX design with robust features like interactive menu filtering, dynamic cart management, instant checkout, and real-time order status updates.
> 
 ★ Key Features
 * **Immersive Hero & Discovery:** Clean landing page highlighting curated dishes, featured chef specials, and quick entry into the full menu.
 * **Dynamic Menu Explorer:**
   * Category tabs (*All, Starters, Mains, Desserts, Beverages*).
   * Dietary filter chips (*Veg, Non-Veg, Vegan, Gluten-Free*).
   * Instant search bar to find dishes instantly by name or description.
 * **Interactive Cart Drawer:** Slide-out drawer featuring itemized pricing, quantity increment/decrement controls, live subtotal, tax calculation, and special cooking instructions text areas.
 * **Seamless Checkout Flow:** Multi-step modal process supporting flexible payment methods (UPI, Cards, Cash on Delivery) with instant order confirmation and generated tracking ID numbers.
